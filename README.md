## Overview

This project develops a machine learning model to estimate medical insurance premiums based on customer demographics and health-related attributes. The workflow covers data preprocessing, exploratory data analysis, feature engineering, model development, and prediction.

---

## Problem Statement

Insurance providers require accurate premium estimation to reduce financial risk while offering fair pricing. This project predicts insurance charges using historical customer information.
